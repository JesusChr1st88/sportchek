# Прогрессия — журнал тренировок и питания

Статический PWA без сборки: ES-модули, офлайн через service worker, синхронизация через Supabase.

- `index.html` — оболочка, `css/app.css` — стиль, `js/app.js` — интерфейс и данные
- `js/engine.js` — вся математика (прогрессия, недели цикла, отказ, рекорды, питание), без DOM
- `npm test` — тесты движка (`node --test`)
- Локальный запуск: `python3 -m http.server` в корне (модули не грузятся через file://)

Данные v2 (`gymlog.v2`) мигрируют автоматически; старая версия сохранена в `index.v2-backup.html`.
